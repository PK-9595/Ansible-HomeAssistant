# Architecture Decision Records

Last verified against codebase: 2026-05-30

This directory is for durable architecture decision records when a significant repository decision needs historical context.

## When To Add An ADR

- Add an ADR when a decision changes deployment architecture, supported platforms, host security posture, persistent storage, networking, or major integrations.
- Do not add ADRs for routine task notes or temporary investigation results.

## Suggested Format

- Title
- Status
- Context
- Decision
- Consequences
- Evidence
